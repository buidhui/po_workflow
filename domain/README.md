# Domain pack

Thư mục này chứa knowledge base của một sản phẩm, theo `engine/standards/domain-kb.md`: manifest `domain.md`, các file KB, corner checklist. Domain không chứa template. Repo engine để trống thư mục này.

Đưa một sản phẩm vào quy trình: tạo repo riêng cho sản phẩm từ repo này, sau đó chạy `/new-domain` và làm theo `DOMAIN-SETUP.md`. Lệnh dựng khung từ `engine/templates/domain/`; người phụ trách cung cấp thông tin theo bảng ở `engine/standards/domain-kb.md` mục 6, sau đó PO cùng AI viết nội dung từng file.
