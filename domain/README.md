# Domain pack

Thư mục này chứa phần riêng của một sản phẩm: manifest `domain.md`, knowledge base, corner checklist, template User Guide. Repo engine để trống thư mục này.

Đưa một sản phẩm vào quy trình: tạo repo riêng cho sản phẩm từ repo này, sau đó chạy `/new-domain` và làm theo `DOMAIN-SETUP.md`. Lệnh dựng khung `domain.md` và các file KB; PO cùng AI viết nội dung.
